# Frontend - Assistente de Inventário

Frontend desenvolvido para o MVP da disciplina de Desenvolvimento Full Stack.

A aplicação auxilia no preenchimento das informações utilizadas na elaboração das Primeiras Declarações de um inventário.

## Tecnologias

- HTML
- CSS
- JavaScript
- API REST desenvolvida em Python e Flask
